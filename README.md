# DMO Reports

Implementation planning, current-state reports, gap maps, runtime evidence summaries, and targeted reconciliation artifacts for the DMO application.

This repository is **not product authority** and **not application source code**.

## Repository roles

- `dmo-app/dmo-authority` — canonical product model.
- `dmo-app/dmo-app-beta` — current application implementation.
- `diogo-o/dmo-reports` — implementation state, plans, gaps, runtime findings, and reconciliation work.
